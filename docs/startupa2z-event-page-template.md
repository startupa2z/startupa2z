# StartupA2Z Event Page Template

Use channel-specific versions of the same core event story. Adapt the facts to the event; do not copy example claims without verification.

## StartupA2Z website event page

1. **Why This Session Matters** — the founder problem, why it matters now, and the practical opportunity.
2. **What You Will Gain** — one concrete attendee outcome per bullet.
3. **About [Speaker]** — verified background, credibility, session contribution, and descriptive profile links.
4. **Who Should Attend** — the people who will benefit and the requirement they are trying to solve.
5. **The [Duration] Session** — exact start/end time and one segment per topic block.
6. **Agenda** — arrival, welcome, each speaker segment, closing, and networking with exact time ranges.
Stop after the agenda. Do not add an About StartupA2Z section, a screenshot of the website, or previous-session recaps to a website event page. Those elements duplicate the host website and distract from the current event and registration CTA.

## Luma event page

Use sections 1–6 above, then add:

7. **About StartupA2Z** — a concise introduction, website link, and current homepage screenshot.
8. **Previous StartupA2Z Sessions** — always last. For each selected previous session include:
   - linked session title;
   - what speakers discussed;
   - one practical takeaway;
   - one group photo shown vertically;
   - a short caption;
   - a full-gallery link.

## Formatting rules

- Use real headings, paragraphs, links, and lists—not newline-only text.
- Keep the attendee value ahead of organizational promotion.
- Never repeat the Luma-only About StartupA2Z and previous-session blocks on the StartupA2Z website itself.
- Use only verified speaker claims and permissioned/public assets.
- Use exact times and ensure session blocks add up to the published event window.
- Keep previous-session images separated by text so Luma renders them vertically instead of as a carousel.
- Preserve established event URLs.
- Verify Luma and the rendered website after every approved release.
